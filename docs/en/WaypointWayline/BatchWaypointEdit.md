### 1. Reverse Start and End Waypoints
![](/img/en-img/WaypointWayline/BatchWaypointEdit/image-0.png)

Click the ![](/img/en-img/WaypointWayline/BatchWaypointEdit/image-1.png) button to swap the start waypoint with the end waypoint, quickly reversing the wayline execution direction.

### 2. Multi-select Waypoints
The waypoint list on the left supports two multi-selection modes.

![](/img/en-img/WaypointWayline/BatchWaypointEdit/image-0.gif)

Shift Multi-select: Select a starting waypoint, then hold Shift + left mouse button and select the ending waypoint to select all waypoints within the specified range.


![](/img/en-img/WaypointWayline/BatchWaypointEdit/image-1.gif)

Ctrl Multi-select: Hold Ctrl + left mouse button to select or deselect individual waypoints.


### 3. Right-Click Menu
After selecting multiple waypoints, right-click in the waypoint list. Batch operation options will appear in the right-click menu.

![](/img/en-img/WaypointWayline/BatchWaypointEdit/image-2.png)

:::tip
**(n) indicates the waypoint number, [n] indicates the quantity of waypoints.**
:::

You can batch apply action templates to selected waypoints, batch delete selected waypoints, clear actions of all selected waypoints, mark all selected waypoints as no-return points, remove the no-return setting from selected waypoints, batch assign POIs to selected waypoints, or remove POI assignments from selected waypoints.

### 4. Batch Editing of Waypoint Parameters
![](/img/en-img/WaypointWayline/BatchWaypointEdit/image-3.png)

After selecting multiple waypoints, select ![](/img/en-img/WaypointWayline/BatchWaypointEdit/image-4.png) on the right panel to batch modify parameters of the selected waypoints. Taking altitude as an example, click

Waypoint altitude to open the batch parameter editing page:

![](/img/en-img/WaypointWayline/BatchWaypointEdit/image-6.png)

You can batch modify parameters, add or subtract parameter values in bulk, or set all parameters to follow global settings. After configuring parameters, click ![](/img/en-img/WaypointWayline/BatchWaypointEdit/image-7.png) to complete batch modification.
