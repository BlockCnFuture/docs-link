Click the ![](/img/en-img/WaypointWayline/SceneSettings/image-1.png) button to configure partial scene settings.

### 1. Virtual flight speed
Set whether the virtual aircraft uses high speed (50 m/s) or low speed (10 m/s) during flight when editing waypoints. Low speed is suitable for simulating and viewing the model from the UAV perspective. Within the wayline editing page scene, use shortcut key X to quickly toggle flight speed.

### 2. Auto-record attitude when adding waypoints
If enabled, when adding new waypoints, actions including UAV yaw, gimbal yaw, gimbal pitch, gimbal roll and camera zoom will be automatically added based on the current attitude and frustum state of the virtual aircraft. This ensures the aircraft maintains the correct attitude when arriving at this waypoint.

### 3. Auto-record attitude when adding recording action
Similar to option (2). It adds a series of attitude actions before the recording action to ensure the aircraft is in the correct attitude before recording starts.

### 4. Preview settings
This option controls the behavior of the virtual aircraft attitude preview function. When a waypoint is selected but no action on this waypoint is selected, the virtual aircraft attitude can display either the departure attitude (after all actions are executed when leaving the waypoint) or the arrival attitude (before executing actions when arriving at the waypoint).
