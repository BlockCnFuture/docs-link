Click the ![](/img/en-img/WaypointWayline/AddWaypoint/image-0.png) button on the left panel to view the waypoint list.

### 1. Direct Addition via Right-Click

![](/img/en-img/WaypointWayline/AddWaypoint/image-1.png)

After adding the reference takeoff point, right-click the target position on the map to add a waypoint. Directly added waypoints **adopt global setting parameters**, which can be manually modified later.


### 2. Relative Addition via Right-Click
If waypoints already exist in the scene, you can add a new waypoint relative to the last waypoint.

![](/img/en-img/WaypointWayline/AddWaypoint/image-2.png)

Waypoints added in relative mode **inherit the setting parameters of the reference waypoint (the last waypoint)**, which can be manually modified later.



### 3. Add Waypoint at Virtual Aircraft Position
During virtual flight, press the Space shortcut key or use the add action to insert a waypoint at the virtual aircraft’s position.

![](/img/en-img/WaypointWayline/AddWaypoint/3.gif)

For waypoints added here, **elevation uses the aircraft elevation, and other parameters match the global settings**, which can be manually modified later.

The aircraft elevation matches global settings by default. It will differ from global settings if manually adjusted.



Press Shift+Space to add a waypoint after the currently selected waypoint (e.g., waypoint No.4). The newly added waypoint inherits all parameters from waypoint No.4.



### 4. Waypoint Styles
![](/img/en-img/WaypointWayline/AddWaypoint/image-4.png)

Waypoints are green ![](/img/en-img/WaypointWayline/AddWaypoint/image-5.png)![](/img/en-img/WaypointWayline/AddWaypoint/image-9.png) when all parameters match global settings.

Waypoints are blue ![](/img/en-img/WaypointWayline/AddWaypoint/image-6.png)![](/img/en-img/WaypointWayline/AddWaypoint/image-10.png) when parameters differ from global settings.

Waypoints are orange ![](/img/en-img/WaypointWayline/AddWaypoint/image-7.png)![](/img/en-img/WaypointWayline/AddWaypoint/image-11.png) when warnings exist (too close to ground, invalid action parameters, etc.).
