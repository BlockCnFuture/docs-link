Select multiple waypoints in the left waypoint list to perform batch action editing.

### 1. Clear Actions
![](/img/en-img/WaypointWayline/BatchActionEdit/image-0.png)

Right-click in the left waypoint list to clear actions for all selected waypoints.

### 2. Batch Modify Action Parameters / Batch Delete Actions
![](/img/en-img/WaypointWayline/BatchActionEdit/image-1.png)

On the right **Actions** ![](/img/en-img/WaypointWayline/BatchActionEdit/image-2.png) panel, you can batch modify action parameters and batch delete actions.

![](/img/en-img/WaypointWayline/BatchActionEdit/image-3.png)

You can set uniform specified parameters, adjust parameters in bulk, or delete all actions of the same type.

After configuring parameters, click ![](/img/en-img/WaypointWayline/BatchActionEdit/image-4.png) to complete the batch operation.
