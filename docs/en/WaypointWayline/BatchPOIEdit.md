### 1. Multi-select POIs
The POI list on the left supports two multi-selection modes.

![](/img/en-img/WaypointRoute/BatchPOIEdit/image-0.gif)

Shift Multi-select: Select a starting POI, then hold Shift + left mouse button and select the ending POI to select all POIs within the specified range.


![](/img/en-img/WaypointRoute/BatchPOIEdit/image-1.gif)

Ctrl Multi-select: Hold Ctrl + left mouse button to select or deselect individual POIs.


### 2. Batch Delete
After selecting multiple POIs, right-click in the POI list to batch delete the selected POIs.

![](/img/en-img/WaypointRoute/BatchPOIEdit/image-0.png)

:::tip
**(n) indicates the POI number, [n] indicates the quantity of POIs.**
:::
