---
title: "Heading Toward POI"
sidebar_position: 15
---
The drone heading at a waypoint can be set to Toward POI. When the drone departs the waypoint after finishing the action, its nose will point toward the POI and rotate smoothly to the initial heading of the next waypoint.

If the heading of the next waypoint is also set to target the same POI, the drone’s heading will rotate smoothly throughout the flight segment from the current waypoint to the next waypoint, continuously pointing toward the POI.

![](/img/en-img/WaypointWayline/HeadingTowardPOI/image-1.gif)

:::tip
**If an action is currently selected, the drone preview prioritizes displaying the state when executing this action. If no action is selected, it shows the state when the drone flies into or departs from the waypoint.**
:::
