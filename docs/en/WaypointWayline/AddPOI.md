## Add POI via Right-Click on Map
After adding the reference takeoff point, right-click the target position on the map to add a POI.

:::tip
**Consumer-grade UAVs currently only support the "Relative to Takeoff Point" altitude mode. When POIs are exported, the software will automatically convert elevations to heights relative to the takeoff point internally. Therefore, the reference takeoff point should be as consistent as possible with the actual takeoff point.**
:::
