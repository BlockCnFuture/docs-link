Refer to [Interface Introduction](./Interface.md) for the entry of wayline operations.

### 1. Rename
Click to modify the name of the wayline.

![](/img/en-img/WaylineManager/WaylineOperations/image-3.png)

### 2. Edit wayline
Click to enter the wayline editing page.

### 3. Export wayline
Click to pop up the wayline export panel for exporting a single wayline.
When exporting a single wayline locally, the software automatically exports the non-interpolated trajectory KML (for flight filing) and survey area KML of the wayline synchronously.
See [Wayline Export](./WaylineExport.md) for details.

### 4. Locate file
Click to view the local path of the wayline file on the device.

![](/img/en-img/WaylineManager/WaylineOperations/image-1.png)

### 5. Duplicate wayline
Create a full backup copy of the wayline with identical parameters. This can be used to quickly create waylines with the same parameters for other devices.

![](/img/en-img/WaylineManager/WaylineOperations/image-2.png)

### 6. Delete wayline
Delete the wayline. This operation cannot be undone.
