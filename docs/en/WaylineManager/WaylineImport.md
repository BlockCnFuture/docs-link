Refer to [Interface Introduction](./Interface.md) for the entry of wayline import.

### 1. Local import
Click this area to select and import multiple DJI standard KMZ waylines from local storage. You can also import by dragging KMZ wayline files into this area.

### 2. External import
Click here to pop up the external import panel. The software automatically detects connected USB devices and can read the wayline list from DJI Fly / DJI Pilot for import. This function does not support iOS devices.

![](/img/en-img/WaylineManager/WaylineImport/1.png)

#### 1. Device list
This section shows devices connected to the PC via USB. You can manually switch devices to read wayline data.

#### 2. Refresh
Click this button to refresh the device list and wayline data.

#### 3. Wayline
Click to select one wayline for import. Only single-wayline import is supported at present.

#### 4. Import wayline
Click to read the wayline file and wayline preview thumbnail (if available) from the mobile device and complete the import.
