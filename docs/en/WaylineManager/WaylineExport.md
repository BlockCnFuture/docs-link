The software can export waylines to local storage, DJI Fly, or removable storage. The exported content includes the wayline KMZ file. For local export, it also contains the survey area KML and non-interpolated flight trajectory KML.

### 1. Wayline splitting
![](/img/en-img/WaylineManager/WaylineExport/image-3.png)

When wayline splitting is enabled, the program exports multiple wayline KMZ files. A set of algorithms ensures that the flight attitude, recording tasks and other settings of each sub-wayline remain consistent with the original single wayline.

### 2. Export wayline to mobile device
![](/img/en-img/WaylineManager/WaylineExport/image-4.png)

After configuring splitting parameters in the wayline export panel, click here to jump to the panel for quick wayline export to mobile devices.

### 3. Generic mobile devices (DJI Fly / DJI Pilot not installed)
![](/img/en-img/WaylineManager/WaylineExport/image-5.png)

For generic devices, the software can automatically export waylines / split wayline segments to Internal Storage or Internal Storage/Download.

### 4. DJI Pilot
DJI Pilot supports wayline import. You can export directly to Internal Storage/Download via the software or manually copy the files, then import the wayline inside DJI Pilot.

### 5. DJI Fly

#### 1. Automatic replacement
DJI Fly does not provide native wayline import. Waylines can only be "imported" by overwriting existing wayline files. The software provides a quick replacement export function (DJI RC or Android devices only).

![](/img/en-img/WaylineManager/WaylineExport/image-7.png)

Connect the smart controller / Android device with DJI Fly installed to your PC via USB and select file transfer mode. The software will list existing waylines in DJI Fly. Select the target wayline to overwrite and click export. The software will automatically replace thumbnails and wayline files.

:::tip
The DJI Fly wayline list may keep thumbnail cache. Refresh the cache to correctly identify waylines afterwards.
Locate the overwritten wayline in the DJI Fly wayline list, rename it and save to refresh the thumbnail cache.
:::

#### 2. Manual replacement
Manual replacement is required when the device cannot be recognized or for iOS devices. Connect the device to PC via USB, open the DJI Fly wayline storage path in File Explorer to replace the wayline. For Android devices:

![](/img/en-img/WaylineManager/WaylineExport/image-8.png)

Navigate to the directory `Android\data\dji.go.v5\files\waypoint\`. Select a target wayline to overwrite (e.g. `1ABD4443-82FC-4FE4-8C0A-DE986951C2A7`). Copy the KMZ file generated by the software into this folder, delete the original `1ABD4443-82FC-4FE4-8C0A-DE986951C2A7.kmz`, and rename the copied KMZ file to `1ABD4443-82FC-4FE4-8C0A-DE986951C2A7.kmz`.

The procedure is identical for iOS, but the iOS wayline directory is: `DJI Fly\wayline_mission\`
