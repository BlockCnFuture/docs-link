### 1. Wayline search
![](/img/en-img/WaylineManager/Interface/1.png)Enter keywords in the search box. The wayline list will filter waylines in real time whose names contain the keywords.

### 2. Create wayline
![](/img/en-img/WaylineManager/Interface/2.png)Click this button to pop up the wayline creation panel.

![](/img/en-img/WaylineManager/Interface/3.png)

Select the wayline type, aircraft and payload to create a wayline and enter the wayline parameter editing page.

### 3. Import wayline
![](/img/en-img/WaylineManager/Interface/4.png)Click this button to pop up the wayline import panel. After importing, you can preview the wayline and modify parameters.
See chapter [Wayline Import](./WaylineImport.md) for details.

### 4. Multi-select waylines
![](/img/en-img/WaylineManager/Interface/5.png)Click this button to enter multi-select mode for the wayline list.

![](/img/en-img/WaylineManager/Interface/6.png)

In multi-select mode, you can batch delete and export selected waylines.

### 5. List sorting
![](/img/en-img/WaylineManager/Interface/7.png)

Set the sorting method of the wayline list from the dropdown list.

### 6. Wayline filter
![](/img/en-img/WaylineManager/Interface/8.png)

Control which aircraft models and wayline types are displayed in the wayline list. Unchecked items will be hidden.

### 7. Basic wayline information
![](/img/en-img/WaylineManager/Interface/9.png)

This section shows basic wayline information, including preview thumbnail, aircraft model, payload model, creation time, update time, wayline type, and favorite status.

![](/img/en-img/WaylineManager/Interface/12.png)Indicates the wayline type. ![](/img/en-img/WaylineManager/Interface/13.png)Indicates whether the wayline is favorited. Click to favorite the wayline.

### 8. Wayline operations
Click the button ![](/img/en-img/WaylineManager/Interface/14.png) in the upper-right corner of the wayline card to perform partial operations on the wayline.
See chapter [Wayline Operations](./WaylineOperations.md) for details.

### 9. Flight simulation
When a wayline is selected, the wayline will be rendered on the map, and the flight simulation button ![](/img/en-img/WaylineManager/Interface/15.png) appears at the upper right of the map. Click it to run flight simulation for the wayline.
See chapter [Flight Simulation](./FlightSimulation.md) for details.

### 10. Wayline pagination
![](/img/en-img/WaylineManager/Interface/16.png)This area shows wayline pagination for page switching.
