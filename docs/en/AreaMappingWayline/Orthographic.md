### Orthographic
For area waylines, select **Orthographic Capture** in the capture mode to generate an orthographic wayline.

![](/img/en-img/AreaMappingWayline/Orthographic/0.png)

### Terrain Follow
This wayline type supports terrain follow. See [AGL](../CommonSettings/FlightAltitude#_3-agl).

Refer to the Common Settings section for other parameters.
