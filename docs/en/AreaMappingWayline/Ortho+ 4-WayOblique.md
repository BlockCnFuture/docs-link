### Ortho + 4-Way Oblique
For area waylines, select **Oblique Capture** in the capture mode and set the oblique mode to "Ortho + 4-Way Oblique".

![](/img/en-img/AreaRoute/QuadOblique/0.png)

### Terrain Follow
This wayline type supports terrain follow. See [AGL](../SharedSets/Height#_3-agl).

Refer to the Common Settings section for other parameters.
