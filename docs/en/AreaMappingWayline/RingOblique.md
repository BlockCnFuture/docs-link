### Ring Oblique
For area waylines, select **Oblique Capture** in the capture mode and set the oblique mode to "Ring Oblique".

![](/img/en-img/AreaRoute/OrbitOblique/0.png)

### Ring Oblique Task Mode
Overlap cannot be set manually for Ring Oblique. However, you can configure the Ring Oblique task mode in advanced settings. Photo overlap varies under different task modes.

![](/img/en-img/AreaRoute/OrbitOblique/1.png)

### Terrain Follow
This wayline type supports terrain follow. See [AGL](../SharedSets/Height#_3-agl).

Refer to the Common Settings section for other parameters.

:::tip
Adjusting the gimbal pitch angle affects the orbit radius.
:::
