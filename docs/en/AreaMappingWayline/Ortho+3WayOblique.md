### Ortho + 3-Way Oblique
For area waylines, select **Oblique Capture** in the capture mode and set the oblique mode to "Ortho + 3-Way Oblique".

![](/img/en-img/AreaMappingWayline/Ortho+3WayOblique/0.png)

### Terrain Follow
This wayline type supports terrain follow. See [AGL](../CommonSettings/FlightAltitude#_3-agl).

Refer to the Common Settings section for other parameters.
