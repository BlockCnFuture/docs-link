### Cross Oblique
For area waylines, select **Oblique Capture** in the capture mode and set the oblique mode to "Cross Oblique".

![](/img/en-img/AreaMappingWayline/CrossOblique/0.png)

### Terrain Follow
This wayline type supports terrain follow. See [AGL](../CommonSettings/FlightAltitude#_3-agl).

Refer to the Common Settings section for other parameters.
