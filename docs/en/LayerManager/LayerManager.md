### 1. Layer search
![](/img/en-img/LayerManager/Interface/1.png)Enter keywords in the search box. The layer list will filter layers in real time whose names contain the keywords.

### 2. Layer filter
![](/img/en-img/LayerManager/Interface/2.png)

Click to pop up a dropdown panel, where you can filter layers of specific types.

### 3. Collapse layer group
![](/img/en-img/LayerManager/Interface/3.png)Click this button to collapse / expand the layer group.

### 4. Show / hide layer group
![](/img/en-img/LayerManager/Interface/4.png)Click this button to hide / show all layers under the layer group.

### 5. Show / hide layer
![](/img/en-img/LayerManager/Interface/4.png)Click this button to hide / show the corresponding layer.

### 6. Add layer
Click the ![](/img/en-img/LayerManager/Interface/5.png) button to add a layer into the layer group.

![](/img/en-img/LayerManager/Interface/6.png)

Different layer groups require different data. It is recommended to quickly add data directly from MipMap Desktop. Link will read local model data under the currently logged-in Desktop account.

![](/img/en-img/LayerManager/Interface/7.png)

:::warning
When data is added to Link, Link does not copy the data; it only records the data path. Deleting the source data will cause the layer to malfunction.
:::

### 7. Clear layer group
Click ![](/img/en-img/LayerManager/Interface/8.png) to clear and delete all layers under the layer group. This operation cannot be undone.

### 8. Locate to layer
Click ![](/img/en-img/LayerManager/Interface/9.png) to quickly locate to the layer position. Location may fail if the layer data is invalid.

### 9. Edit layer
Click ![](/img/en-img/LayerManager/Interface/10.png) to modify the layer model data path, rendering parameters, layer name, etc.

### 10. Delete layer
Click ![](/img/en-img/LayerManager/Interface/8.png) to delete the corresponding layer. This operation cannot be undone.
