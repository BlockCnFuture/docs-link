title: "Safe Takeoff Height"
sidebar_position: 7
---

![](/img/en-img/CommonSettings/SafeTakeoffHeight/0.png)

This setting applies only to industrial drones and is not available for consumer drones.

After configuring the safe takeoff height, the aircraft will climb to the specified height upon takeoff, then fly to the start point of the flight mission.

For example, if the safe takeoff height is set to 20 meters, the aircraft will first climb to 20 meters above the takeoff location before proceeding to the mission start point to ensure operational safety.
