### 1. Import
![](/img/en-img/CommonSettings/AOI/0.png)

Survey areas in KML format can be imported here. Click the import button to select and import a KML file, or drag and drop the KML file into the dashed area.

### 2. Export
![](/img/en-img/CommonSettings/AOI/1.png)

When a survey area has been imported or drawn, you can export it as a KML file using the export button, or clear the survey area with the clear button.
