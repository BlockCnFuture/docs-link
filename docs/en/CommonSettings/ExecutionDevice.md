This section displays the name of the current flight mission, aircraft model, and gimbal model. Click to modify relevant information.

![](/img/en-img/SharedSets/Device/1.png)

If you change the aircraft model or gimbal model, the software will automatically check parameter availability. Unsupported parameters will be removed. It is recommended that you back up the mission using the "Duplicate Mission" function before making changes.
