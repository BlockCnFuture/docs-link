title: "Save Wayline"
sidebar_position: 53

![](/img/en-img/SharedSets/SaveWayline/0.png)

The software does not auto-save waylines. After confirming all changes to parameters, waypoints and other settings, click this button to save data. When saving the wayline, the preview image will be automatically generated or updated. The preview is rendered using an orthographic camera in top-down view.

If you exit the page with unsaved changes, a prompt will notify you of unsaved data.

![](/img/en-img/SharedSets/SaveWayline/1.png)

The Save button will be disabled when there are no pending changes to save.

![](/img/en-img/SharedSets/SaveWayline/2.png)
