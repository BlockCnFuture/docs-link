A reference takeoff point must be set before you can draw the survey area, adjust GSD, and perform other operations.

:::warning
Upon takeoff, the aircraft ignores mission settings and uses the physical takeoff location as the relative takeoff point. This may introduce flight safety risks for close-range missions.

Therefore, for **consumer-grade** aircraft or when the altitude mode is set to **Relative Takeoff Altitude**, the **reference takeoff point should match the actual takeoff location as closely as possible**.
:::

When creating a mission for the first time, left-click on the map to place the reference takeoff point. If a reference takeoff point already exists, click "Reset Takeoff Point" to redefine it.

The reference takeoff point supports translation and elevation adjustment. Left-click the reference takeoff point icon on the map to select and activate it.

While active, hold the left mouse button on the reference takeoff point and drag the mouse to translate it; release the left mouse button to finish editing.

While active, hold Alt + left mouse button on the reference takeoff point and drag the mouse to adjust its elevation; release the left mouse button to finish editing.
