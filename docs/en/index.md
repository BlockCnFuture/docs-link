## Software Overview

### Feature List
| **Feature** | |
| --- | --- |
| **1** | **Support mission planning for industrial / consumer-grade UAVs** |
| **2** | **Support waypoint missions, nadir mapping missions, four-oblique / three-oblique / grid oblique / orbit oblique missions, and inclined surface mission planning** |
| **3** | **Export mission KMZ, track KML, and survey area KML to local storage / remote controller / mobile device / USB flash drive** |
| **4** | **Import standard KMZ missions from local storage / DJI Pilot / DJI Fly, with preview and editing capabilities** |
| **5** | **Overlay local Mipmap Desktop / third-party DOM / PNTS / B3DM tiles and GeoTIFFs into the scene** |
| **6** | **Support mission flight simulation and simulation video recording** |
