Double-click the installer package (MipMapLink.exe). Select the installation target as required, click Next, choose the installation directory, then click Install to complete the MipMap Link installation.

![](/img/en-img/FirstUse/SoftwareInstallation/image-0.png)

MipMap Link requires hardware acceleration for smooth rendering of 3D scenes. The software will check whether hardware acceleration is available upon startup and prompt you if it is not. The software can still run without hardware acceleration, though rendering frame rates may be significantly degraded.

![](/img/en-img/FirstUse/SoftwareInstallation/image-1.png)
