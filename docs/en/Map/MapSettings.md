Some settings are available at the upper-right and lower-right corners of the map.

### 1. Camera follow settings

Left-click ![](/img/en-img/Map/MapSettings/image-18.png) to change the camera follow mode. Camera follow takes effect during waypoint editing and flight simulation.

![](/img/en-img/Map/MapSettings/image-19.png)

### 2. Flight Simulation

Enter the flight simulation interface. See chapter [Flight Simulation](../WaylineManager/FlightSimulation).

### 3. Orientation compass

![](/img/en-img/Map/MapSettings/image-1.png)The compass indicates the map azimuth in real time. Left-click the compass to quickly rotate the map to true north.

### 4. Display mode
![](/img/en-img/Map/MapSettings/image-2.png)This shows whether the current map uses 3D display mode (perspective camera) or 2D display mode (orthographic camera).

When tilting the camera view with the middle mouse button, the map automatically switches to 2D mode when nearly top-down, and switches back to 3D mode when the tilt angle becomes large.

Left-click ![](/img/en-img/Map/MapSettings/image-3.png) to quickly toggle between 3D / 2D display modes. When switching to 2D via left-click, the map is locked in 2D mode ![](/img/en-img/Map/MapSettings/image-8.png). You may still rotate the map, but the camera tilt angle cannot be modified. Click again to switch to 3D and unlock automatically.

While in 2D display mode, right-click ![](/img/en-img/Map/MapSettings/image-4.png) to manually lock the display mode, or right-click ![](/img/en-img/Map/MapSettings/image-9.png) to unlock it.

### 5. Map zoom
Left-click ![](/img/en-img/Map/MapSettings/image-5.png) to zoom in the scene slightly. Left-click ![](/img/en-img/Map/MapSettings/image-10.png) to zoom out the scene slightly.

### 6. Locate
Left-click ![](/img/en-img/Map/MapSettings/image-6.png) to trigger map location.

![](/img/en-img/Map/MapSettings/image-11.png)

You can locate to custom longitude, latitude and height:

![](/img/en-img/Map/MapSettings/image-12.png)

Or locate to the current wayline position.

![](/img/en-img/Map/MapSettings/image-14.png)

### 7. Base map
Left-click ![](/img/en-img/Map/MapSettings/image-7.png) to switch the base map.

![](/img/en-img/Map/MapSettings/image-13.png)
